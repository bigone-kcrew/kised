# 2026년 3분기 노사협의회 노측 안건 — 실무협의 설명자료

창업진흥원 노동조합이 2026. 9. 28. 3분기 노사협의회 정기회의에 상정할 노측 안건 10건의
실무협의용 발표자료.

| 문서 | 주소 |
| --- | --- |
| 발표자료 (슬라이드) | https://bigone-kcrew.github.io/kised/ |
| 안건 전문 | https://bigone-kcrew.github.io/kised/agenda.html |

발표자료는 요약입니다. 근거 조문과 세부 요구는 **안건 전문**에 있습니다.
슬라이드 왼쪽 아래 문서 아이콘으로도 갈 수 있습니다.

## 보는 법

| 환경 | 이동 |
| --- | --- |
| PC | 좌우 방향키 · 좌측 목차 클릭 · 숫자키 1~9(안건 이동) |
| 모바일 | 좌우로 밀기 · 하단 이동 바 · 가운데 번호를 눌러 목차 |

그 밖의 단축키 — `F` 전체화면 · `N` 발표 노트 · `T` 밝은 화면 · `H` 목차 숨기기

인쇄하거나 PDF로 저장하면 슬라이드당 한 페이지로 나옵니다.

## 구성

안건 하나가 목차의 한 항목이다. 좌측 목차(모바일은 하단 가운데 번호)에서 안건별로 바로 갈 수 있다.

| 순서 | 내용 |
| --- | --- |
| 표지 | |
| 안건 목록 | 10건 한눈에 · 눌러서 이동 |
| ①~④ | 임신검진 동행휴가 · 장기재직휴가 · 휴일검진 대체휴무 · 자율출퇴근제 |
| ⑤ | 근무평정 사후조정 도입 (5장) |
| ⑥ | 임직원 법률지원제도 (3장) |
| ⑦ | 사내근로복지기금 (2장) |
| ⑧ | 공공기관 통폐합 대응 (4장) |
| ⑨~⑩ | 퇴직자 위원 · 제도 안내와 캠페인 |
| 자료 요청 | 협의에 필요한 집계 자료 |

## 고치는 법

슬라이드는 `deck/slides/*.html` 에 있다. 파일 하나가 장(章) 하나이고,
그 안의 `<section class="slide">` 하나가 슬라이드 한 장이다.
순서는 **파일명 문자열 정렬**로 정해지므로 중간에 끼울 때는 `02b-` 처럼 접미문자를 쓴다.

```
python3 build.py     # deck/shell.html + deck/slides/*.html -> index.html
```

빌드 스크립트는 작업 저장소에 있다.

## 만든 것

슬라이드 틀(`deck/deck.css`·`deck.js`)은 창업진흥원 근무평정 제도개선 발표덱에서 가져와
모바일 이동(스와이프·하단 바·목차 토글)을 더한 것이다.
